# 🏥 IoMT — Internet of Medical Things

A real-time patient health monitoring system that collects sensor data (heart rate, SpO₂, temperature) and proactively flags potential health risks.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Flask](https://img.shields.io/badge/Flask-Web_App-green)

## Features
- Real-time vitals streaming
- Automatic risk detection (NORMAL / WARNING / CRITICAL)
- Live web dashboard
- Historical data tracking
- REST API endpoints

## Tech Stack
Python · Flask · JavaScript · HTML/CSS

## Run
```bash
pip install -r requirements.txt
python app.py
